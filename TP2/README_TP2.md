## Objetivos de la Actividad
* Implementar componentes de **Bootstrap** mediante el uso de **CDN**.
* Estructurar una página web con secciones de encabezado, cuerpo y pie de página.
* Configurar elementos interactivos de navegación visual (Carousel).

## Descripción de las Actividades

### 1. Desarrollo en Visual Studio Code
Se debe realizar un proyecto HTML que integre Bootstrap para crear una interfaz con las siguientes características:

* **Encabezado (Header):** Debe contener un **Carousel** de imágenes.
    * El Carousel debe incluir exactamente **tres imágenes**.
    * Debe poseer botones funcionales para desplazar los slides hacia los laterales (izquierda y derecha).
* **Cuerpo (Body):** Un sector destinado a mostrar información general del proyecto.
* **Pie de página (Footer):** Debe incluir información de contacto referida a la fuente de donde se tomó la información.

### 2. Formato de Entrega
La presentación del trabajo práctico se realizará a través de la plataforma oficial cumpliendo con lo siguiente:
* **Documentación:** El archivo debe ser un documento en formato **Word** o **PDF**.
* **Contenido:** Se deben incluir capturas de pantalla que demuestren las mejoras e implementaciones incorporadas al proyecto mencionado.
